# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. A small monorepo of npm workspaces (`@acme/ui`, `@acme/core`) and a Go workspace (`example.com/svc`, `example.com/lib`), the manifests of issue 5 for the JavaScript and Go ecosystems (FR124 to FR129). The package.json sentinel (`preinstall` in `@acme/core`) would write a marker file if a script ran (FR079, SC015). `scripts/orphan.ts` sits under a package.json that declares no name, so no project contains it. The expected facts in `expected.json` are written by hand from these files: one `project` symbol per named manifest, at the line of its name, and each declared dependency as `depends_on` (inside the repository) or `depends_on_package` (outside it), at the line that declares it. Cargo, pyproject and Composer manifests are not in this fixture yet.
