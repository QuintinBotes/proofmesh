# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. The `StandIns` project declares minimal stand-ins for Microsoft.Extensions.DependencyInjection, ASP.NET Core MVC and minimal API routing, Refit, MediatR, Microsoft.Extensions.Hosting, Microsoft.Extensions.Configuration, and Confluent.Kafka, with the real namespaces, type names, and parameter names, so the fixture needs no package or framework reference.

The fixture covers each built-in rule across three projects, so cross-project rules (constructor injection, MediatR dispatch, a Refit call to an endpoint another project exposes) are exercised. It also holds the negative cases: types named like the framework types in other namespaces (`Contoso.Decoys`, and `Microsoft.Extensions.DependencyInjectionSpecs` for the namespace-prefix boundary), and routes, keys, topics, request types, and factory results that are not statically known.

`expected.json` is hand-written from the source and the frameworks' documented semantics, and never generated by Proofmesh.
