# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. One small file per language whose names the stable-key slice (FR146 to FR150) fixes: Go (receivers), Java (overloads and a package), Rust (`impl` blocks), Python (a property and its setter) and C (a prototype and its definition). The SCIP index for `go/cart.go` and `java/Shop.java` is not produced by any indexer: `packages/proofmesh/test/stable-keys.test.ts` encodes it by hand. The expected keys are written by hand in that test.
