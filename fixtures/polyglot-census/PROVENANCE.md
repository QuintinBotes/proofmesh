# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. One tiny file per kind of row the language census (FR136 to FR141) must list: TypeScript (precise tier), Go and C and an extensionless Bash script (syntax tier), C# (its adapter made unavailable by the test), Elixir and an ERB template (no grammar), and data and prose files. `packages/proofmesh/test/census.test.ts` writes the expected rows by hand from the spec table of issue 3.
