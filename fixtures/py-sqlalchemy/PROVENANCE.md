# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code, and `sqlalchemy` is deliberately not installed. Declarative classes with `__tablename__`, a Core `Table("order_lines", metadata, ...)` assigned to a module-level name and mapped to a class through `__table__`, a subclass without `__tablename__` that shares its parent's table (single-table inheritance), a subclass with its own table (joined inheritance), and a `__tablename__` computed by a call, which must stay unresolved. `dynamo.Table("sessions")` takes a single argument, as boto3's DynamoDB tables do, and must yield no table. Entry points reach the tables: a FastAPI router included under a prefix (`store/api.py`, `store/main.py`) and a Celery `@shared_task` (`store/tasks.py`), with neither `fastapi` nor `celery` installed. The expected facts in `expected.json` are written by hand.
