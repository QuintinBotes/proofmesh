# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. A Maven reactor (`com.acme:shop` with modules `core` and `web`) and a Gradle build (`:app`, `:lib`), the JVM build files of issue 13 (FR151 to FR160); Bazel (`bazel/BUILD.bazel`: `//bazel:util` with a glob and `//bazel:main` with a local and an external dependency) and Buck (`buck/BUCK`: `//buck:calc`) are the Bazel and Buck files of the same issue (FR246 to FR249). Three kinds of sentinel would write a marker file if the build ran: an `exec` plugin bound to `validate` in `maven/web/pom.xml`, a task and a top-level statement in `gradle/app/build.gradle.kts`, and a `genrule` in `bazel/BUILD.bazel` (FR079, SC015). `gradle/lib/build.gradle` adds one dependency in a `for` loop, which is not read statically.
