# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. `Audit` deliberately does not exist. The EF Core and ASP.NET Core types are stand-ins.

The endpoint `GET api/orders/{id}/summary` reaches `Summaries.Describe` through the interface `ISummaries`. It reads `Order.CustomerId`, `Order.Total`, `Customer.Name` and `Created`, which the base type `Entity` declares; it only writes `Notes`, and the `Id` assignments in `Store` are writes. `Reports.Discounts` reads `Discount` but no endpoint reaches it. `property-reads.json` is a hand-written sample of what an instrumented run might observe. `expected.json` is hand-written and never generated by Proofmesh.

`CustomerQueries.All` reads the context's `Customers` DbSet property and nothing else, so `GET api/customers/all` reaches the `Customers` table only through that read: endpoint, controller action, `CustomerQueries.All`, the property, the table.
