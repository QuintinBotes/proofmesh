# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. The EF Core and ASP.NET Core types are stand-ins.

Two endpoints reach the `Orders` table. `GET api/orders/open` is owned by `Crew.Billing`, reads `Order.State` and calls `Trellis.Twine`, which the note in `notes/` says writes the clause `@pN = @pN`; `GET api/reports/{id}/total` is owned by `Crew.Search` and reads `Order.Total`. `GET api/customers/{id}` reaches only `Customers`. The statement in `expected.json` filters on `State`, carries the tag clause, and names `Billing` in its comment. Scores follow the documented weights: 4 per table, 3 for the owner, 3 per helper, 2 per matching column. `expected.json` is hand-written and never generated by Proofmesh.
