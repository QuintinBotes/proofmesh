# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code, and `django` is deliberately not installed, so `models.Model` resolves only through the import of `django.db.models`, while the abstract `TimeStamped` base is a workspace class Pyright resolves. Two apps: `shop/models.py` and the `billing/models/` package. An abstract model, a proxy model, `Meta.db_table`, `Meta.app_label`, multi-table inheritance, and a plain class with a `Meta.db_table` that is not a model and must yield no table. `recent()` reaches `Order` only through `Order.objects`, which cannot resolve without Django. Entry points reach the tables: `config/urls.py`, named by `ROOT_URLCONF`, includes `shop/urls.py`, which routes a function view and a class-based view whose `post` builds a gift order. The expected facts in `expected.json` are written by hand.
