# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. One small file per language whose syntax-tier query records import statements and heritage clauses (FR115, FR116): Go, Java, Kotlin, Rust, PHP and Ruby (FR221, FR222), then Swift, Scala, C, C++ and Bash (FR224, FR225), and the call sites of C and C++ (FR226). The expected facts in `expected.json` are written by hand from these files: each import statement is one unresolved `imports` row with the module as written, each named supertype is one unresolved `inherits` or `implements` row from the type that names it, and each call is one unresolved `calls` row, because this tier never resolves a name (FR117).
