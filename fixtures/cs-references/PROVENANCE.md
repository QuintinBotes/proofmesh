# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. `Missing.Thing` deliberately does not exist.

`expected.json` is hand-written and never generated by Proofmesh. It lists every reference the C# adapter must record in `src/Shop/Orders.cs` (closed world): one per user and target, at its first site, with every way the user touches the target.

The external calls are `List<Order>` construction and `Add` (System.Collections), `Enumerable.Select` (System.Linq) and the `InvalidOperationException` constructor (System.Runtime), the reference assemblies that declare them.
