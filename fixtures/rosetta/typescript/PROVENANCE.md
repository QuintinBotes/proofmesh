# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. The Rosetta program for this language: a single-project TypeScript program (interface, two classes implementing it, a function over the interface, a direct call, a report module importing the shapes module and a test function). Its `expected.json` is written by hand from the program and from the documented behaviour of each tier, never generated by the code under test (see `../PROVENANCE.md`).
