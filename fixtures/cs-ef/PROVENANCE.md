# Provenance

Project-authored for Proofmesh. Apache-2.0. The EF Core and EF6 types are minimal stand-ins declared in the fixture, so it needs no package. They cover the DbSet convention for both versions, EF6 pluralization with and without the convention removed, ToTable with constant and computed names, ToTable inside an EntityTypeConfiguration, and the [Table] attribute.

`expected.json` is hand-written and never generated by Proofmesh.

Added for EF6 pluralization, fluent registration and table-per-hierarchy: `Payment` has no explicit mapping and its context keeps the pluralizing convention, so its table is the inferred `Payments`; `Shipment` is registered only by `builder.Entity<Shipment>()`; `RushOrder : Order` and `CreditNote : Invoice` are subtypes that share their base's table, which the query layer reports through `inherits`.

Added for lightweight conventions (EF6 `Types().Configure`): `LedgerContext` names every table `"tbl_" + c.ClrType.Name`, so `Ledger` maps to `tbl_Ledger`; `VoucherContext` names tables after `Registered(c.ClrType).Name` with the schema `promo`, so `Voucher` maps to `promo.Voucher`, marked inferred because the helper could map a type to another.

`GiftContext` derives from `VoucherContext` and adds a lightweight convention that only ignores a property; it names no table, so `Gift` takes `VoucherContext`'s naming: `promo.Gift`, inferred.

`Shop.Archive` is a second project whose `ArchiveContext` derives from `VoucherContext` in `Shop.Legacy`: the base context's convention reaches across projects, so `Bundle` maps to `promo.Bundle`, inferred.
