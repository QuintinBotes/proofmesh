# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. Three repositories for cross-repository symbols (#28): `lib/` builds the package `@fx/geo` 1.2.0; `app/` depends on it, builds the package `fx-app` 1.0.0 and has a test, `src/route.test.ts`; and `map/` depends on `fx-app`. `installed/geo/index.d.ts` is the declaration file `@fx/geo` installs, and `installed/route/index.d.ts` the one `fx-app` installs; since `node_modules` is never committed, the test writes each, with a `package.json` of the version under test, into a copy of the repository that uses it, at `node_modules/@fx/geo` or `node_modules/fx-app`. The expected rows are written by hand in `packages/proofmesh/test/xrepo-symbols.test.ts`.
