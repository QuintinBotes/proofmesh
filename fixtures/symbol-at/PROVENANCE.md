# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. One small file per tier the symbol-at tool (FR119 to FR123) must answer for: TypeScript, Python, Go (syntax tier), C#, a Go file covered by a SCIP index, Terraform, and a README no adapter reads. The SCIP index is not produced by any indexer: `packages/proofmesh/test/symbol-at.test.ts` encodes it by hand, with no enclosing range on its definition. The expected rows are written by hand in that test from the line numbers of these files.
