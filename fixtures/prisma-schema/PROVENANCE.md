# Provenance

Project-authored for Proofmesh. Apache-2.0. No third-party code. Two Prisma schemas: a blog's, split across the files of `prisma/schema/` with a schema per model (`@@schema`), and an audit service's in one file. The expected facts in `expected.json` are written by hand from these files: each model and view is a class mapped to its table, which `@@map` names (rule `prisma_map`) or, without one, the model's own name (rule `prisma_convention`, marked inferred), qualified by its `@@schema`. A field whose type is a model in the same file references it. `Post.author` names `User`, which another file declares, so it is unresolved; `User.posts` names a model of another file without `@relation`, so it is not reported, like a field of an enum type such as `User.role`.
