# Proofmesh plugin for Claude Code

A skill that tells agents to call Proofmesh before searching by hand and to verify absence claims; an MCP registration that starts `proofmesh mcp`; commands (`/proofmesh:status`, `/proofmesh:index`, `/proofmesh:impact`, `/proofmesh:trace`, `/proofmesh:verify-claim`); and freshness hooks. After an Edit or Write inside a registered repository, and at session start when `proofmesh status --fresh` finds the working tree differs from the snapshot, the hook records the change and one background runner per repository runs `proofmesh index` once edits have been quiet for four seconds; the agent is told that answers are as of the previous snapshot until it publishes. The runner's state and log live under the system temporary directory (`proofmesh-hooks-<uid>`). Install `proofmesh` first (A13). This plugin replaces the predecessor's plugin surface (A15).
